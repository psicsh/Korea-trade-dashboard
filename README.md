# 한국무역 한눈에 보기 v8.4

v8.3의 모바일 차트 개선을 유지하면서 모바일/PC 모두 밝은 테마로 통일한 버전입니다.

## v8.4 핵심
- 전체 배경: 밝은 회청색 `#F4F7FB`
- 카드·표·차트 영역: 흰색
- 헤더: 기존 짙은 남색 유지
- 글자: 짙은 남회색
- 모바일 브라우저/기기 다크모드 영향을 줄이기 위해 CSS에 `color-scheme: light` 강제
- Streamlit 기본 입력창·선택창·탭·Metric·표도 밝은 배경으로 고정
- Altair 그래프 배경을 흰색으로 고정하고 축/글자색을 어두운 색으로 지정
- v8.3의 가로 막대그래프, 0 기준 축, 당월 제외, 반응형 표, 지역 상세 기능 유지

백엔드 자동 업데이트와 안전장치는 변경하지 않았습니다.
