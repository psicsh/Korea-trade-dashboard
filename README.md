# 한국무역 한눈에 보기 v9.0

## 핵심 변경
v8.x의 산업통상부 보도자료/PDF 자동수집과 GitHub Actions를 완전히 제거했습니다.

v9.0은 다음 구조입니다.

- 전체 무역: 관세청 수출입총괄 Open API
- 20대 품목: 관세청 HSK 품목별 Open API + 2026 HSK-MTI 공식 연계표
- 9대 지역: 관세청 국가별 Open API + 지역 국가코드 합산
- HS 상세조회: 관세청 품목별 Open API
- 최신월: 매월 16일 이후 전월, 1~15일에는 전전월을 기본 확정월로 사용
- 캐시: 6시간

## 딱 한 번 필요한 설정
한국무역협회에서 아래 파일을 다운로드합니다.

`2026 MTI-HSK 코드표_vFF_260507.xlsx`

그 파일을 GitHub 저장소의 `data/` 폴더에 넣고 이름을

`mti_hsk_mapping.xlsx`

로 바꿉니다.

공식 게시 페이지:
https://www.kita.net/board/pressData/pressDataDetail.do?no=12102
