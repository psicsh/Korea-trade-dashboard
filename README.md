# 한국무역 한눈에 보기 v8.2

v8.1의 자동 업데이트 기능을 유지하면서 실제 PC/모바일 화면을 다듬은 버전입니다.

## v8.2 화면 수정
- 휴대폰에서 20대 품목·9대 지역 표가 주변 배경과 어울리도록 반응형 자체 표로 변경
- 앱 테마를 light로 고정해 모바일 다크모드에서 표만 흰색으로 튀는 현상 완화
- 전체 무역의 수출·수입 증감률에 `전년동월 대비` 명시
- 9대 지역 선택 시 최신 수출액과 전년동월 대비 증감률 즉시 표시
- 관세청 월별 그래프에서 진행 중인 당월 제외
- 최대 수출 품목 금액에 잘못 붙던 상승 화살표 제거
- 감소 지역은 감소율을 직접 표시
- 학생용 화면에서 자동화 누적 안내 문구 제거

백엔드 자동 갱신·검증 로직은 v8.1과 동일하게 유지합니다.
